GeoJSON API

Use GeoJSON

Request building features as standard GeoJSON for web maps, scripts, and data integrations.

1Request features

Add outputFormat=GEOJSON to a WFS GetFeature request.

curl "__GEOJSON_URL__"

2Limit the result

Use a bounding box and count when you only need features near the current map view.

curl "__FILTERED_GEOJSON_URL__"
ParameterPurpose
typeNames=plansReturns building plan features.
bbox=minX,minY,maxX,maxYFilters features spatially. Coordinates default to EPSG:4326.
count=100Limits the number of returned features.
featureId=Point.1Returns one known feature by its GML identifier.
srsName=EPSG:3857Requests Web Mercator coordinates instead of EPSG:4326.

3Read the response

The response is a GeoJSON FeatureCollection. Structured properties such as floors are returned as native JSON arrays when supported by the current GeoPackage.

{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "geometry": {
        "type": "Point",
        "coordinates": [151.2074, -33.8662]
      },
      "properties": {
        "GmlID": "Point.1",
        "buildingName": "Example Building",
        "floors": ["Ground Level", "Level 1"],
        "buildingCode": "bld_example"
      }
    }
  ]
}

Need XML? Omit outputFormat. The default WFS response is XML, where structured values may be formatted as readable delimited text.

ArcGIS integration

Add ESP layers to ArcGIS

Use WFS for queryable building features and WMTS for rendered floor-plan imagery.

WMTS requires multiple layers. ESP publishes coverage and each floor level as separate WMTS layers. Add every coverage or floor layer your map needs; adding one WMTS layer does not ingest the complete floor-plan set.

Features and attributes

Add the WFS plans layer

Use this connection for building points and attributes such as campus, building, and floor names.

__WFS_URL__

ArcGIS Pro

  1. Open Insert > Connections > Server > New WFS Server.
  2. Paste the WFS URL above into Server URL, select WFS version 2.0.0, and click OK.
  3. Expand the new connection under Servers in the Catalog pane, then add the plans layer to the current map.
  4. To request native JSON values such as the floors array, add the custom request parameter OUTPUTFORMAT=GEOJSON and use snapshot mode.

ArcGIS Online Map Viewer

  1. Choose Add > Add layer from URL.
  2. Paste the WFS URL, choose OGC WFS web service, and click Next.
  3. Select the plans layer, set an appropriate maximum feature limit, and click Add to map.
Rendered floor plans

Add the WMTS floor layers

Use this connection for cached floor-plan imagery aligned to the map.

__WMTS_URL__

ArcGIS Pro

  1. Open Insert > Connections > Server > New WMTS Server.
  2. Paste the WMTS capabilities URL above into Server URL and click OK.
  3. Expand the WMTS connection in the Catalog pane and add each required layer, such as Coverage, Ground Level, and Level 1.

ArcGIS Online Map Viewer

  1. Choose Add > Add layer from URL, paste the WMTS URL, and choose OGC WMTS web service.
  2. Click Next, choose one layer and its matrix tile option, then click Add to map.
  3. Repeat the entire add-layer process for every additional coverage or floor layer required by the map.

Use a Web Mercator-compatible basemap. ArcGIS requires the WMTS tiling scheme and the map's basemap coordinate system to be compatible.
